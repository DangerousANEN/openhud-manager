Инженерия и архитектура

Архитектура сквозного конвейера данных (Data Flow)

Обработка пакетов Valve CS2 GSI и векторный радар на 18 соревновательных карт

1. Приём телеметрии (GSI)
  • Слушатель Axum 0.7
    HTTP-приемник пакетов Valve Source Engine по спецификации GSI на порту :1349.
  • Совместимый порт-мост
    Обработка входящих пакетов на порту :31982 с проверкой токена авторизации.
  • Парсинг SteamID фокуса
    Чтение нативного поля player.steamid с авто-фолбэком на getSteamID.
2. Ядро и персистентность
  • In-Memory State (Tokio)
    Атомарное обновление структуры MatchSnap в асинхронном рантайме.
  • SQLite в режиме WAL
    Асинхронные задачи Tokio для записи истории раундов без блокировки сетевого цикла.
  • Компактный бинарник
    Легковесный нативный стек без накладных расходов виртуальной машины JS.
3. Трансляция и радар
  • WebSocket Broadcast (Realtime)
    Событийная рассылка данных матча в оверлеи OBS Studio по локальному сокету.
  • Векторный радар (18 карт)
    Удален черный фон: прозрачный альфа-канал с контурным неоновым свечением.
  • Точные мировые координаты
    Прямой множитель scale Valve Source 2 без ошибок инверсии и выпадения маркеров.

✓ Подтверждено автотестами (Verified)
  • E2E тесты веб-камер 3 HUD
    Успешно декодируются видеокадры, muted playback, сохранение DOM при пакетах GSI, переключение фокуса между игроками.
  • Геометрия оверлеев
    Проверено на 1280×720, 1920×1080 и 2560×1440. Отсутствуют наложения блоков и выходы за границы экрана.
  • Типографика ростеров
    Математически подтверждена однострочная посадка длинных никнеймов игроков через Range.getClientRects.
  • Бэкенд-инженерия
    33 E2E теста бэкенда пройдены успешно; 36 модульных тестов библиотеки и 5 интеграционных тестов camera_storage выполнены без ошибок.
• Границы валидации и ограничения (Honest Disclosure)
  • Windows Native GUI Signoff
    Бинарник protokol-hud-manager.exe (18.8 МБ) и установщик NSIS (114 МБ) собраны и проверены по SHA-256; запуск нативного GUI Windows находится в статусе ожидания финального signoff.
  • Синтетические видеопотоки
    Текущие скриншоты оверлеев зафиксированы на сгенерированных тест-паттернах (SMPTE таймкод); сквозная турнирная сессия CS2 в боевых условиях пока не подтверждена.
  • Отсутствие невалидированных бенчмарков
    В релизных материалах исключены неподтвержденные бенчмарки RAM и задержек, а также громкие маркетинговые статусы. Версия приложения — 0.1.0.
