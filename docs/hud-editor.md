# Редактор HUD

[← к оглавлению](README.md)

Визуальный конструктор оверлеев. Собирает HTML-страницу для OBS Browser Source
перетаскиванием блоков, без ручной вёрстки.

## Холст

Ровно 1920×1080 — размер кадра трансляции. Внутри окна масштабируется, но
координаты остаются в пикселях кадра: то, что видно в редакторе, попадёт в
эфир в тех же местах.

Привязка к сетке 8 пикселей. Блоки цепляются к общим линиям, поэтому
выравнивание получается само.

## Блоки

| Блок | Что показывает |
|---|---|
| Счёт матча | счёт, названия и логотипы команд |
| Таймер раунда | время раунда, фаза, статус бомбы |
| Составы | пятёрки, живые и мёртвые, HP |
| Экономика | деньги команд, оружие |
| Killfeed | лента убийств |
| Спонсоры | ротация логотипов по весу |
| Текст | произвольная подпись |

Блок добавляется из библиотеки слева, ставится на холст, дальше настраивается
справа.

## Свойства

Координаты X и Y, ширина и высота, слой (z-index), прозрачность, размер шрифта,
цвета текста и фона. Отдельное поле для своего CSS, если нужного параметра в
панели нет.

Слои перечислены списком: порядок меняется перетаскиванием, каждый можно скрыть
или продублировать.

## Сохранение

Макеты лежат в SQLite, в таблице `hud_layouts`. Сохранённый макет открывается
на любой машине, где стоит приложение с той же базой.

В браузере вне Tauri (`npm run dev`) вместо базы используется localStorage —
чтобы разработка не падала на отсутствии бэкенда.

## Экспорт

Экспорт собирает самодостаточный HTML: разметка и стили внутри одного файла,
внешних зависимостей нет. Такой файл кладётся в
`%APPDATA%\OpenHUD\overlays\<имя-пака>\` и добавляется в OBS как Browser
Source.

Размер источника в OBS — 1920×1080, ровно как холст. Другой размер даст
несовпадение координат.

## Подключение к OBS

1. В OBS: Источники → плюс → Браузер.
2. URL: адрес из страницы «HUD-паки» или `file:///` до экспортированного файла.
3. Ширина 1920, высота 1080.
4. Галка «Выключить источник, когда не отображается» — снять, иначе оверлей
   будет терять связь по WebSocket при переключении сцен.
