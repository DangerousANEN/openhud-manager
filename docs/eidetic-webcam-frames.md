# Вебкам-рамки для нативного cs-hud (Eidetic Fennec)

Оригинальный EidecticHM не рисует рамку веб-камеры кодом — он ищет **картинки-оверлеи**
и кладёт их поверх HUD. Ты кладёшь свои PNG, HUD сам их подхватывает.

## Куда класть

В папку `%APPDATA%\EideticHM\` (сервер создаёт её сам при старте), файлы:

| Файл | Что это |
|---|---|
| `overlay-images/focused-player-bottom.png` | Рамка вокруг карточки наблюдаемого игрока (низ центра). Тоже место под вебку |
| `overlay-images/sidebar-left.png` | Рамка левого сайдбара (CT) |
| `overlay-images/sidebar-right.png` | Рамка правого сайдбара (T) |

Форматы: пробуются `.webp`, затем `.png`, затем `.gif`.

## Как это работает в коде

`src/themes/fennec/focused-player/focused-player.js` делает
`fetch('/hud/overlay-images/focused-player-bottom.webp')` и если файла нет — просто
не показывает картинку. Поэтому без файлов HUD выглядит «без вебки».

## Как вставить камеру

1. Положи PNG-рамки (готовые лежат в `docs/eidetic-overlay-images/`)
2. В OBS добавь источник **Video Capture Device** ПОД браузер-источником с HUD
   (или браузер поверх камеры — рамка PNG прозрачна в окне)
3. Совмести камеру с прозрачным окном рамки
