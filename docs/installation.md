# Установка и первый запуск

[← к оглавлению](README.md)

## Готовый установщик

1. Скачать `OpenHUD-HUD-Manager_0.1.0_x64_ru-RU.msi`.
2. Запустить, пройти установщик.
3. Первый старт создаёт рабочий каталог и базу данных.

SmartScreen на неподписанном сборке покажет предупреждение — «Подробнее» →
«Выполнить в любом случае». Подпись кода в планах.

## Сборка из исходников

Понадобится Node.js 18+, Rust stable, Visual Studio Build Tools с компонентом
Desktop development with C++.

```bash
git clone <репозиторий>
cd openhud-manager
npm install
npm run tauri dev      # разработка с горячей перезагрузкой
npm run tauri build    # релизная сборка + MSI
```

Первая сборка Rust занимает несколько минут: тянутся и компилируются axum,
rusqlite с bundled SQLite и rcon. Дальше инкрементально — секунды.

Готовый установщик появится в
`src-tauri/target/release/bundle/msi/`.

## Где лежат данные

| Что | Путь |
|---|---|
| База данных | `%APPDATA%\OpenHUD\openhud.db` |
| Оверлеи | `%APPDATA%\OpenHUD\overlays\` |

Точный путь к базе всегда виден на странице «Настройки» — там же кнопка
открытия каталога в проводнике.

База — обычный файл SQLite. Резервная копия делается копированием файла при
закрытом приложении. Открыть и посмотреть можно любым браузером SQLite.

## Проверка после установки

Открыть «Настройки» — в блоке состояния должно быть, что сервер слушает порт
1349. Если порт занят, поменять его там же и перезапустить приложение.

Дальше — [подключение CS2](gsi-setup.md).
