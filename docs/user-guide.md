# Руководство пользователя

[← к оглавлению](README.md)

Одиннадцать страниц в левом меню, сгруппированы по смыслу: эфир, управление,
оформление, настройки.

## Live

Что происходит в матче прямо сейчас: счёт, фаза раунда, таймеры, обе команды
пятёрками, деньги и оружие по игрокам. Данные приходят из GSI и обновляются
несколько раз в секунду.

Индикатор связи сверху — единственное место, где видно, дошёл ли GSI. Если он
неактивен, всё остальное на странице покажет нули.

## Матчи

Матч связывает две команды, турнир и формат (bo1, bo3, bo5). Текущий матч
помечается — его данные уходят в оверлеи, поэтому названия и логотипы в эфире
берутся отсюда, а не из GSI.

## Команды

Название, тег, логотип, страна. Тег — короткая форма для тесных мест в оверлее,
три-четыре знака.

Логотип лучше квадратный PNG с прозрачным фоном, 512×512. Прямоугольные будут
обрезаны по центру.

## Игроки

Ник, реальное имя, страна, команда, роль. Ник должен совпадать со Steam-ником:
по нему данные из GSI сшиваются с карточкой игрока. Расхождение — и в оверлее
вместо реального имени останется ник из игры.

## Турниры

Название, даты, призовой фонд, логотип. Матчи ссылаются на турнир, оверлеи
берут отсюда шапку.

## HUD-паки

Список готовых наборов оверлеев из `%APPDATA%\OpenHUD\overlays\`. У каждого
своя ссылка для OBS Browser Source, копируется кнопкой.

Активный пак помечается, событие об этом уходит в оверлеи по WebSocket.

Импорт из архива пока не сделан — новый пак ставится копированием папки в
каталог оверлеев, потом обновить список.

## Редактор HUD

Свой оверлей на холсте 1920×1080 без вёрстки руками. Подробно —
[hud-editor.md](hud-editor.md).

## Трансляция

Сцены, реплеи, титры-плашки. Всё это рассылается в оверлеи по WebSocket:
оверлей ловит событие и меняет своё содержимое.

Рядом — панель OBS. Если obs-websocket включён (в OBS: «Сервис» →
«Настройки WebSocket-сервера»), а host/порт/пароль заполнены в Настройках,
панель показывает статус подключения и даёт кнопки: старт/стоп стрима,
старт/стоп записи, сохранить реплей.

Сопоставление сцен задаётся там же: у каждой сцены приложения выпадающий
список сцен OBS. Выбрал — сохраняется сразу. После этого клик по сцене
приложения переключает и сцену в OBS. Где сопоставление не задано, работает
только слой оверлеев.

## Спонсоры

Название, логотип, вес показа, активность. Оверлей с блоком спонсоров
крутит их по весу — чем больше, тем чаще.

## Серверы

CS2-серверы и RCON-консоль. Подробно — [rcon-servers.md](rcon-servers.md).

## Настройки

Порт сервера, путь к базе, текст GSI-конфига, поля подключения к OBS.

Поля OBS (`obs_host`, `obs_port`, `obs_password`) читает модуль управления
OBS на странице Трансляция. Пароль нужен, только если в OBS включена
аутентификация.
