# Серверы и RCON

[← к оглавлению](README.md)

Source RCON — штатный протокол удалённого управления игровым сервером по TCP.
Приложение подключается к серверу, авторизуется паролем и выполняет консольные
команды.

## Добавление сервера

На странице «Серверы»: название, хост или IP, порт (по умолчанию 27015), пароль
RCON. Пароль на сервере задаётся параметром `rcon_password` в конфиге или
ключом запуска `+rcon_password`.

Кнопка «Связь» проверяет подключение: таймаут 5 секунд на коннект, 10 на
команду, поэтому мёртвый сервер не подвесит интерфейс.

## Пароль

Пароль хранится в SQLite и **не отдаётся во фронтенд**: список серверов
приходит с пустым полем пароля и флагом, задан он или нет. В логи пароль не
попадает.

При редактировании сервера пустое поле пароля означает «оставить прежний».

Ограничение, о котором надо знать: в базе пароль лежит открытым текстом. Файл
базы защищён только правами пользователя Windows. Для машины на площадке этого
обычно достаточно, но если приложение уйдёт клиентам — шифрование обязательно.

## Консоль

Произвольные консольные команды с историей. Полезное для турнирной практики:

```
status                    список игроков и их Steam ID
mp_pause_match            пауза
mp_unpause_match          снять паузу
mp_backup_restore_list_files    список бэкапов раунда
mp_backup_restore_load_file <файл>   откат на раунд
say <текст>               сообщение в чат
changelevel <карта>       сменить карту
```

## Смена карты

Отдельный блок для `changelevel`. Это то место, где сходятся серверы и
спонсорские баннеры: варианты одной карты с разными баннерами лежат в одном
Workshop-аддоне, переключение между ними — одна команда.

```
changelevel de_mirage_pk_intel
changelevel de_mirage_pk_amd
```

`changelevel` перезапускает карту и выкидывает всех в загрузку. Переключать
между картами матча или в перерыве, не посреди раунда.

Про подготовку самих карт с баннерами — в отдельном руководстве по
спонсорским баннерам CS2.

## Что не проверено

Протокол реализован крейтом `rcon 0.6.0`, команды компилируются и вызываются,
но проверки с живым CS2-сервером не было. Первое подключение покажет, всё ли в
порядке с передачей аргументов.
