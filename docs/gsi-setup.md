# Подключение CS2 через GSI

[← к оглавлению](README.md)

Game State Integration — штатный механизм Valve: игра сама отправляет состояние
матча HTTP-запросами на указанный адрес. Ничего не инжектится в процесс игры,
VAC к этому не имеет отношения.

## Конфиг

Приложение генерирует текст конфига на странице «Настройки» — кнопка копирования
рядом. Сохранить его в файл:

```
<Steam>\steamapps\common\Counter-Strike Global Offensive\game\csgo\cfg\gamestate_integration_openhud.cfg
```

Имя файла обязано начинаться с `gamestate_integration_` — иначе игра его не
подхватит.

Содержимое:

```
"OpenHUD Manager"
{
    "uri"           "http://127.0.0.1:1349/gsi"
    "timeout"       "5.0"
    "buffer"        "0.1"
    "throttle"      "0.1"
    "heartbeat"     "30.0"
    "data"
    {
        "provider"                  "1"
        "map"                       "1"
        "round"                     "1"
        "player_id"                 "1"
        "player_state"              "1"
        "player_weapons"            "1"
        "player_match_stats"        "1"
        "allplayers_id"             "1"
        "allplayers_state"          "1"
        "allplayers_match_stats"    "1"
        "allplayers_weapons"        "1"
        "allplayers_position"       "1"
        "phase_countdowns"          "1"
        "bomb"                      "1"
    }
}
```

Секции `allplayers_*` отдаются игрой только наблюдателю. С обычного клиента
придут данные лишь по себе — это ограничение Valve, не приложения.

## Проверка

1. Запустить приложение, дождаться сообщения о старте сервера на 1349.
2. Запустить CS2, зайти на карту хоть с ботами: `map de_dust2`.
3. Открыть страницу «Live» — индикатор станет активным, побегут данные.

Если тихо: перезапустить CS2 (конфиг читается только при старте), проверить
имя файла и что порт в конфиге совпадает с портом в настройках.

## Наблюдатель на матче

Данные по всем десяти игрокам приходят с машины, которая смотрит матч как
наблюдатель — GOTV или live-обсервер. Схема на площадке: обсервер запускает CS2
с этим конфигом, приложение работает на той же машине или на соседней в
локальной сети.

Для соседней машины в `uri` вместо `127.0.0.1` ставится её IP, а порт 1349
открывается в брандмауэре Windows.
