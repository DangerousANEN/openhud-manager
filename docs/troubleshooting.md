# Что делать, когда не работает

[← к оглавлению](README.md)

## GSI не приходит

Страница «Live» пустая, индикатор неактивен.

- CS2 перезапускался после создания конфига? Файл читается только при старте.
- Имя файла начинается с `gamestate_integration_`?
- Конфиг лежит в `game\csgo\cfg\`, а не в корне игры?
- Порт в конфиге совпадает с портом в настройках?
- Порт 1349 не занят другим процессом: `netstat -ano | findstr 1349`

## Видно только одного игрока

Данные по всем десяти отдаются игрой только наблюдателю. С обычного клиента
придут данные лишь по себе. Нужен GOTV или live-обсервер.

## Оверлей чёрный в OBS

- Размер источника ровно 1920×1080?
- Снята галка «Выключить источник, когда не отображается»? Иначе WebSocket
  отваливается при переключении сцен.
- Открывается ли адрес оверлея в обычном браузере? Если нет — дело не в OBS.
- Кэш браузерного источника: правый клик по источнику → «Обновить кэш».

## Кнопки сцен не переключают OBS

По порядку:

- В OBS включён WebSocket-сервер? «Сервис» → «Настройки WebSocket-сервера» →
  галка «Включить сервер WebSocket».
- Порт совпадает с полем в Настройках? По умолчанию 4455.
- Если в OBS стоит галка «Включить аутентификацию» — пароль в Настройках
  обязателен, и это именно пароль из OBS, а не любой свой.
- Панель OBS на странице Трансляция показывает «подключён»? Если «нет связи» —
  под шапкой панели написана причина.
- Сцена сопоставлена? Пустой выпадающий список рядом со сценой означает, что
  переключать в OBS нечего. Нажмите «Обновить сцены», выберите сцену OBS.
- Имя сцены в OBS переименовали после сопоставления — сопоставление слетело,
  выберите заново.

## Пак не появился в списке

Папка лежит прямо в `%APPDATA%\OpenHUD\overlays\`, а не вложена ещё на
уровень? Внутри есть `index.html`? После копирования список надо обновить.

Через импорт из архива: вставьте полный путь к ZIP в поле на странице HUD и
нажмите «Установить». Если архив упакован с одной обёрточной папкой внутри,
она разворачивается автоматически. Ошибка «в архиве нет index.html» означает,
что оверлей лежит глубже одного уровня — перепакуйте так, чтобы `index.html`
был в корне архива или в единственной папке верхнего уровня.

## RCON не подключается

- `rcon_password` задан на сервере?
- Порт RCON открыт и совпадает с указанным? Обычно 27015.
- Сервер отвечает вообще: `telnet <host> 27015`?
- Хостинг-панели иногда дают отдельный порт RCON, не равный игровому.

Проверки с живым сервером не проводилось, так что ошибка может быть и на
стороне приложения — сообщение об ошибке в консоли покажет, где именно.

## Имя игрока не подставляется

Ник в карточке игрока должен совпадать со Steam-ником символ в символ. GSI
сшивает данные по нику.

## База сломалась

База — файл SQLite. Закрыть приложение, скопировать
`%APPDATA%\OpenHUD\openhud.db` в сторону, попробовать открыть браузером
SQLite. Если файл побит — удалить, приложение создаст новый при старте
(данные потеряются).

Резервные копии делаются простым копированием файла при закрытом приложении.

## Сборка из исходников падает

- `error: failed to select a version` — версия зависимости в `Cargo.toml`
  не существует на crates.io. Проверить доступные:
  `cargo search <крейт>`
- ошибки линковки на Windows — не хватает Visual Studio Build Tools с
  компонентом Desktop development with C++
- `npm run build` жалуется на типы — `vue-tsc --noEmit` показывает файл и
  строку, править по месту
