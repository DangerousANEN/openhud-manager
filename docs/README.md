# OpenHUD Manager — документация

Продакшн-пакет для турнирных трансляций CS2. Десктопное приложение: приём
Game State Integration, хостинг оверлеев для OBS, каталог участников,
визуальный редактор HUD и управление серверами через RCON.

Версия 0.1.0 · Windows · Tauri 2 + Vue 3 + SQLite

## Что готово, а что нет

Готово и проверено запуском:

- приём GSI на порту 1349 с раздачей по WebSocket
- хостинг оверлеев для OBS Browser Source
- каталог команд, игроков, матчей, турниров, спонсоров
- визуальный редактор HUD с сохранением в SQLite
- страница серверов с RCON-консолью и сменой карты
- управление OBS по obs-websocket v5: статус, список сцен, переключение сцены
  по сопоставлению, стрим и запись, сохранение реплея
- импорт и удаление HUD-паков из ZIP-архива

Не проверено на живом железе:

- **RCON.** Протокол реализован, разбор пакетов покрыт тестами, но сессии с
  настоящим CS2-сервером не было.
- **OBS.** Хендшейк и команды реализованы по протоколу v5, с запущенным
  OBS Studio не проверялись.

## Требования

- Windows 10 или 11
- CS2 с правами на правку `csgo/cfg`
- OBS Studio 28+ (Browser Source)
- свободный порт 1349

Права администратора не нужны: приложение пишет только в свой каталог в
`%APPDATA%`.
